# Доешь

Навигатор по холодильнику для Android. Продиктуйте вслух, что у вас есть, — приложение
подберёт рецепты из того, что реально лежит на полке, и спишет продукты, когда вы
приготовите.

Всё работает офлайн: база рецептов лежит в приложении, содержимое холодильника хранится
на устройстве. Ни аккаунтов, ни сервера, ни ключей API. Единственное обращение наружу —
системное распознавание речи Android.

## Как это работает

1. **Голос.** Нажимаете микрофон и говорите одним предложением: «молоко, три яйца,
   помидоры и куриное филе». Знаки препинания не нужны — разбор на них не опирается,
   потому что Android их обычно и не ставит.
2. **Подтверждение.** Распознанное показывается списком: можно поправить количество,
   удалить лишнее, добавить забытое через поиск. Всё, что не удалось опознать,
   выносится отдельно — сказанное не теряется молча.
3. **Рецепты.** Вкладка «Что приготовить» раскладывает 79 рецептов по секциям:
   наверху «Пора доесть» — то, что использует скоропортящееся, дальше можно готовить
   сейчас, не хватает одного, почти получается.
4. **Списание.** Кнопка «Приготовил» вычитает израсходованные продукты из холодильника.

Срок годности указывать не обязательно: по умолчанию продукт хранится бессрочно.
Если нужно, срок задаётся в карточке продукта, в том числе разный для частей — три палки
колбасы, одна до завтра, другая через две недели. При готовке первым списывается то, что
испортится раньше. Рецепты, которые съедают скоропортящееся, поднимаются в раздел «Пора доесть».

О сроках приложение напоминает само: в день срока — «доешь сегодня», наутро после — «пора
выбросить». В холодильнике то же видно плашкой, а просроченное выбрасывается одной кнопкой —
уходят только испорченные партии, свежие остаются. Лишнее можно удалить и вручную, отметив
несколько продуктов сразу.

Любимые рецепты отмечаются сердечком и собираются на вкладке «Избранное» вместе с теми,
что вы готовите чаще всего.

## Запуск

Нужны Android SDK и JDK 17. **Expo Go не подойдёт** — распознавание речи это нативный
модуль, требуется dev build.

```bash
npm install
npx expo run:android
```

Первая сборка занимает 10–20 минут, последующие — секунды.

Голосовой ввод стоит проверять **на физическом устройстве**: у эмулятора микрофон
работает только при включённой опции «Virtual microphone uses host audio input», а
речевые сервисы Google есть лишь в образах с Play Store. Без них приложение честно
скажет об этом и предложит ручной поиск.

## Разработка

```bash
npm test           # тесты: разбор речи, партии и сроки, подбор рецептов, списание
npx tsc --noEmit   # типы
npx expo lint      # линтер
```

Устройство отвечает за качество распознавания само, поэтому самое хрупкое место —
разбор транскрипта. Он покрыт тестами: составные числительные, единицы измерения,
отсутствие запятых, нераспознанные фрагменты.

`android/` не хранится в гите — нативный проект генерируется из `app.json`. После правки
плагинов или разрешений выполните `npx expo prebuild --platform android --clean`.

Подробности архитектуры и подводные камни — в [AGENTS.md](AGENTS.md).

## Как добавить рецепт или продукт

Рецепты — в `src/data/recipes.ts`, продукты — в `src/data/ingredients.ts`. Каждый
`ingredientId` в рецепте обязан существовать в справочнике. У нового продукта
перечислите падежные формы в `forms`: автоматический стемминг русскую морфологию
не вытягивает.
